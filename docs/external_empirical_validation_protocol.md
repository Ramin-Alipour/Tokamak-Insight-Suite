# External empirical validation protocol (spectroscopy benchmark + independent reference)

Status date: 2026-10-15

## Acceptance rule
A test counts as empirical validation only when all four are archived:
1. Traceable experimental input, with origin and processing state explicitly classified (detector/raw, calibrated, digitized from a published figure, or already processed).
2. A documented analysis method with units, assumptions, calibration and versioned code.
3. An independent published/reference result for the same signal, channel, shot, time window, calibration and convention.
4. A reproducible numerical comparison (absolute and relative difference, uncertainty where available) and a regression test.

A plot, a synthetic fixture, a formula check, or comparison against a result generated by the same code is not empirical validation. Never silently promote processed or figure-digitized data to raw. A missing independent comparable reference means candidate/integration test, not validated.

## Primary article benchmark: Aditya-U carbon-ion spectroscopy

Open-access article: Shukla et al., “Poloidal Rotation and Edge Ion Temperature Measurements Using Spectroscopy Diagnostic on Aditya-U Tokamak,” Atoms 7 (2019), 93.
Article: https://www.mdpi.com/2218-2004/7/3/93
DOI: https://doi.org/10.3390/atoms7030093

The article reports C2+ emission at 464.74 nm, analyzed Aditya-U shot 33057, spectra collected during 90–110 ms with a 20 ms CCD exposure, wavelength dispersion 0.01446 ± 0.0008 nm/pixel, an instrumental FWHM of 0.039 nm measured using an Hg line at 435.8 nm, and edge ion temperatures of 32–40 eV. It shows measured spatially resolved spectra and describes correction for instrumental broadening using squared-width subtraction, followed by an Abel-like inversion of line-integrated values.

Important data limitation: the article is open access and includes plotted spectra/results, but a downloadable machine-readable detector-count spectrum was not verified. A curve digitized from the article figure is NOT raw detector data. Do not label such a curve as raw, and do not claim full empirical validation from it. Use this paper as the primary method/reference target while locating the authors' original numerical spectra or a repository supplement.

Required steps:
- Request the original numerical spectral arrays from the corresponding author or locate a public repository/supplement.
- Preserve original bytes, SHA-256, retrieval timestamp, source URL and metadata.
- Verify wavelength calibration, instrument line-spread function, background handling, selected chord, exposure/time window and fitting convention.
- Reproduce line fit, instrumental-width correction, Doppler temperature and uncertainty independently.
- Compare against the paper's same-chord/same-shot reported result only after matching definitions and processing; report absolute difference (eV), relative difference (%) and uncertainty.
- Add a regression test and data only when redistribution terms permit.

## GOLEM 30622: demoted to a secondary diagnostic/data-quality candidate

Source page: https://golem.fjfi.cvut.cz/shots/30622/Data.php

Do not use GOLEM 30622 as the primary ion-temperature benchmark. The archived value previously cited for this shot is labelled electron temperature, not a direct ion-temperature reference. The spectrum's exact processing state, wavelength calibration and instrument line-spread function have not been established as matching the current Doppler fit. Thus a Ti comparison against that Te value is invalid.

The shot can still be used for import/parser and provenance checks after downloading the exact linked file and recording its metadata. It must not be used to validate Ti unless a like-for-like independent ion-temperature reference and calibration are found.

## Alternative literature benchmark: START Doppler spectroscopy

Carolan et al., “A Doppler Spectroscopy Diagnostic to Study the Ion Temperature, Rotation and Confinement in Neutral-Beam-heated START Plasmas” (1998).
Article discovery page: https://www.researchgate.net/publication/252311585_A_doppler_spectroscopy_diagnostic_to_study_the_ion_temperature_rotation_and_confinement_in_Neutral-Beam-heated_START_plasmas

The article presents raw spectra and instrument-response functions in figures and reports Ti increasing from approximately 50 to 350 eV in a representative NBI-heated discharge, with comparisons to Neutral Particle Analyzer data. It is a useful high-temperature comparison target, but the underlying numeric spectra must be obtained and provenance/licensing checked before being used as machine-readable test data.

## Reporting labels
- PASS — empirical: all four acceptance items above are satisfied and numerical discrepancy is reported.
- PASS — integration only: real external data downloaded and processed, but no independent comparable reference.
- CANDIDATE: promising source or article, but data, calibration, or reference matching is incomplete.
