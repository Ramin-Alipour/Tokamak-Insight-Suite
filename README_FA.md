# Tokamak Insight Suite (TIS) — نسخهٔ 0.3.0

**سامانهٔ پایتون برای بررسی داده‌های تشخیصی توکامک، محاسبات پایهٔ فیزیک پلاسما و ثبت منشأ داده‌ها**

این پروژه یک برنامهٔ مستقل پایتون است. متن مرجع همراه مخزن در `docs/reference/tokamak_reference_extracted.txt` قرار دارد و از سند ۲۴ صفحه‌ای `tokamak.pdf` موجود در Library استخراج شده است. خود PDF در این مخزن کپی نشده است؛ بنابراین اجرای نرم‌افزار به فایل PDF وابسته نیست.

## اجرا

نیازمندی: Python 3.10 یا جدیدتر.

### Windows

1. ZIP را در پوشه‌ای دلخواه استخراج کن.
2. در همان پوشه ترمینال باز کن و اجرا کن:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

اگر PowerShell فعال‌سازی محیط را مسدود کرد، می‌توان مستقیماً از `.venv\Scripts\python.exe -m pip install -r requirements.txt` و سپس `.venv\Scripts\python.exe -m streamlit run app.py` استفاده کرد.

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

مرورگر معمولاً خودکار باز می‌شود؛ در غیر این صورت نشانی محلی نمایش‌داده‌شده در ترمینال را باز کن.

## قابلیت‌های پیاده‌سازی‌شده

- ورود CSV، TXT، Excel و Parquet؛ بررسی ابعاد، داده‌های گمشده، مقادیر غیرمتناهی، آمار پایه و SHA-256 فایل ورودی.
- پردازش سری زمانی: بررسی یکنواختی زمان‌نمونه‌برداری، فیلتر Butterworth با فاز صفر، FFT، چگالی طیفی توان Welch، همدوسی، طیف متقاطع و هم‌بستگی متقاطع.
- طیف‌سنجی: برازش Gaussian، Lorentzian و Voigt؛ مرکز خط، پهنا، مساحت/دامنه و R²؛ محاسبهٔ اختیاری سرعت خط دید و دمای داپلری فقط با فرض‌های اعلام‌شده.
- پروب لانگمویر: تحلیل I–V، پتانسیل شناور، مشتق dI/dV، برازش ناحیهٔ تأخیری الکترون، تخمین Te و تخمین مشروط چگالی یونی با سطح جمع‌آوری و مدل غلاف واردشده؛ همچنین تخمین سادهٔ دمای triple-probe با فرض‌های صریح.
- کالیبراسیون خطی با انتشار عدم‌قطعیت، کالیبراسیون چندجمله‌ای و برازش طول موج از خطوط مرجع.
- محاسبات پایه: فشار الکترونی/یونی، فرکانس پلاسما، طول دبای، چگالی گرینوالد، توان اهمی تقریبی، بتا، زمان محصورسازی و سرعت صوت یونی تقریبی.
- حل توموگرافی خطی با منظم‌سازی Tikhonov، وارون‌سازی Abel با فرض تقارن محوری، انتگرال‌گیری توان تابشی از شبکهٔ تابندگی و مشتقات میدان از شبکهٔ شار پولوییدی واردشده؛ هندسه/شبکه باید با دستگاه واقعی سازگار باشد.
- تحلیل هم‌فازی حسگرها برای برآورد عدد مد، شار کوواریانسی ذرات/گرما از داده‌های هم‌زمان، برازش نمایی شار حرارتی هدف، توصیف گرادیان پروفایل‌ها، ممان‌های طیف انرژی و تبدیل نرخ شمارش نوترون با بازده و عامل هندسی واردشده.
- کتابخانهٔ قابل جست‌وجوی تشخیص‌ها و فرمول‌ها، خروجی JSON/CSV و ثبت مشخصات پروژه، فایل، زمان ورود و هش ورودی؛ داشبورد تیره با ناوبری سمت چپ بر اساس تصویر مرجع ذخیره‌شده در `docs/design_reference_dashboard.png`.
- نمونهٔ مصنوعی سیگنال MHD در `examples/sample_mhd_signal.csv`؛ دادهٔ مصنوعی است و دادهٔ آزمایش واقعی نیست.

## آزمون‌ها

```bash
python -m pytest -q
```

آزمون‌های نسخهٔ 0.3.0 در محیط ساخت اجرا شدند: **۳۹ آزمون موفق**. آزمون‌ها شامل کالیبراسیون، فیلتر، FFT، PSD، همدوسی، برازش خطوط، محاسبات پایه، توموگرافی، کیفیت داده و پوشش کاتالوگ‌اند. آزمون واحد به‌تنهایی جایگزین اعتبارسنجی با دادهٔ مرجع مستقل و دستگاه واقعی نیست.

## مرزهای علمی — مهم

این نرم‌افزار ابزار پژوهشی است، نه سامانهٔ کنترل یا حفاظت توکامک. خروجی‌های استنباطی از اندازه‌گیری مستقیم تفکیک شده‌اند. برای هر دستگاه واقعی، پاسخ دستگاه، کالیبراسیون، هندسهٔ خط دید، نرخ نمونه‌برداری، قرارداد علامت، عدم‌قطعیت و فرض‌های مدل باید ثبت شوند.

نسخهٔ 0.3.0 گردش‌کارهای بیشتری برای تشخیص‌های متداول دارد؛ بااین‌حال همهٔ خانواده‌های موجود در PDF به‌عنوان حل‌گر تخصصی کامل پیاده‌سازی نشده‌اند. حل Grad–Shafranov/EFIT، مدل‌های اتمی collisional-radiative، بازسازی کامل توزیع یون‌های سریع، ray tracing، تحلیل کامل ذرات runaway، پردازش اختصاصی تصاویر و آشکارسازهای دستگاه‌ویژه به کدها و داده‌های اختصاصی نیاز دارند. صفحهٔ تعادل فعلی مشتقات شبکهٔ شار ورودی را محاسبه می‌کند و حل‌گر تعادل نیست. این موارد در کاتالوگ به‌عنوان مسیر تحلیل و محدودیت مستند شده‌اند، نه قابلیت تکمیل‌شده.

## منبع دامنهٔ علمی

- سند اصلی ۲۴ صفحه‌ای: `tokamak.pdf` در Library کاربر (در مخزن کپی نشده است)
- متن استخراج‌شده همراه پروژه: `docs/reference/tokamak_reference_extracted.txt`
- فهرست تشخیص‌ها و فرمول‌ها: `DIAGNOSTIC_REGISTRY.json` و `FORMULA_REGISTRY.json`

عنوان‌های منابع بیرونی که در PDF مرجع ذکر شده‌اند، به‌عنوان سرنخ کتاب‌شناختی حفظ شده‌اند؛ وجود نام منبع در PDF به معنی اعتبارسنجی مستقل همهٔ روابط یا پیاده‌سازی آن‌ها در نرم‌افزار نیست.

## اجرای دسته‌ای از خط فرمان

پس از نصب وابستگی‌ها، بدون باز کردن رابط گرافیکی می‌توان اجرا کرد:

```bash
python -m tis.cli qc examples/sample_mhd_signal.csv --output qc_report.json
python -m tis.cli fft examples/sample_mhd_signal.csv --signal mirnov_ch1_V --time time_s --output fft.csv
python -m tis.cli catalog --kind both --output-dir exported_catalogs
```

فرمان `qc` گزارش کیفیت و هش فایل را می‌سازد؛ `fft` دو خروجی FFT و Welch PSD تولید می‌کند؛ `catalog` فهرست روابط و تشخیص‌ها را صادر می‌کند.
